The archive includes the visualizer source files, Docker setup, and example algorithms from the `manimVisualizer` folder.

## Quick Start

After extracting the archive, you can run the visualizer with:

```bash
manim -pql --resolution 1920,1080 manimTest.py -- --mainScene <your-file.py>
```

Sample inputs are included in the `examples/` directory.
